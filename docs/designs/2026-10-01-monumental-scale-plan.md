# Monumental Scale Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make The Ring feel monumental. Add a reusable atmosphere kit, rebuild the monument at ×4 around an unscaled player, and make the engine safe at that scale.

**Architecture:**
- The Ring is scene data generated by `tools/gen_ring.py`, with one `SCALE` constant. The player, eye height and body tests stay absolute.
- Engine limits that silently depended on ×1 geometry become level properties or derived values:
  - sweep sample density;
  - sweep tolerance;
  - overview camera distance;
  - isometric marker size.
- Atmosphere is a small runtime module plus an authored backdrop scene selected per level.

**Tech Stack:** Godot 4.7.2 (Steam), GDScript, Compatibility renderer; Python 3 for scene generators.

**Spec:** [2026-10-01-monumental-scale.md](2026-10-01-monumental-scale.md)

## Global Constraints

- **Engine and renderer:** Godot 4.7.2, `gl_compatibility`; every visual must work in Compatibility.
- **Monuments are scene data:** no per-level gameplay script, no runtime procedural layout. Generators write `.tscn` files offline.
- **Scale:** The Ring `SCALE = 4`. Player size, eye height (1.55 m), `pose_is_clear` padding, eye clearance (0.1 m) and the near plane (0.04) never scale.
- **Fixtures stay ×1:** `tests/fixtures/*.tscn` are not rescaled, and the synthetic levels in `curve_cases` stay ×1.
- **Puzzle invariant:** the Ring minimum stays 6 turns / 16 actions; the 16-configuration connection table and tower necessity are unchanged.
- **Self-test:** `"$G" --headless --path . monuments/the_ring.tscn --quit-after 900 --log-file test.log -- --self-test` must print `AUTHORING SELF TEST PASS` with no `SCRIPT ERROR`. Here `G="/c/Program Files (x86)/Steam/steamapps/common/Godot Engine/godot.windows.opt.tools.64.exe"`.
- **Eye clearance:** `"$G" --headless --path . -s res://tests/eye_clearance_probe.gd -- res://monuments/the_ring.tscn` exits 0.
- **Commits:** every commit message ends with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`. Work on `feature/monumental-scale`; push, never merge without a request.
- **Never kill the user's Godot editor process.** Godot may re-save `.uid` files on import; commit them with the file they belong to.

## Review Focus

1. **Off-centre arrival at the goal on a 25 m-wide terrace** must still complete. The goal's `trigger_radius` scales with the monument (Task 5, test `goal_reach_cases`).
2. **An old revision-3 Ring save** must be rejected cleanly and the monument must start fresh, not restore a ×1 position into ×4 geometry (Task 5).
3. **A player who changed any setting before** has `fov = 72` saved; the new 60° default must still reach them unless they chose a value after this change (Task 4, preference migration test).
4. **Turn latency at ×4:** denser sweep sampling must not freeze the game when Q/E is pressed. A full ring sweep check must take under 500 ms headless (Task 2).
5. **The backdrop never acts as architecture:** it is never pickable, never a sweep obstacle, never a camera obstacle, and never blocks walking (Task 4).

  - `ElsewhereLevel.overview_distance() -> float`;

  - `func sweep_reach(entry: Dictionary) -> float`;
  - `func sweep_samples(entry: Dictionary, interval: Vector2) -> int`.

**Why 0.25 m:** sampling every 0.1 m at r ≈ 35 m gives ~1100 samples per half turn of SAT tests in GDScript, which is too slow for Q/E. The thinnest solid in either scale is the 0.26 m curve deck at ×1, so a 0.25 m step can never jump a solid. Record this change from the design's 0.1 m in the design doc (Task 7).

```gdscript
## Monumental scale: turn sweeps stay dense and fast at any size, the tolerance is the level's,
## and the overview camera stands clear of tall masses.
static func sweep_cases(g: Node3D, failures: Array[String]) -> void:
	g.build_level()
	if not is_equal_approx(g.sweep_tolerance, g.definition.sweep_tolerance): failures.append("The runtime must use the level's sweep tolerance")
	for entry in g.rigs:
		for direction in [-1, 1]:
			var interval: Vector2 = g.rotation_interval(entry, direction)
			var samples: int = g.sweep_samples(entry, interval)
			var step: float = g.sweep_reach(entry) * absf(interval.y - interval.x) / samples
			if samples < 60 or step > g.SWEEP_STEP + .000001: failures.append("%s sweep moves %.3f m between samples" % [entry.node.name, step])
		var started := Time.get_ticks_msec()
```

```gdscript
## Farthest any solid of a turning structure reaches from its pivot (box corners included).
func sweep_reach(entry: Dictionary) -> float:
	var pivot: Vector3 = entry.node.global_position
	var reach := 0.0
	for moving in entry.solids:
		reach = maxf(reach, moving.global_position.distance_to(pivot) + (moving.mesh as BoxMesh).size.length() * .5)
	return reach

## Sweep samples by arc length: the farthest solid moves at most SWEEP_STEP between samples.
func sweep_samples(entry: Dictionary, interval: Vector2) -> int:
	var angle := absf(interval.y - interval.x)
	return maxi(60, maxi(int(ceil(angle / deg_to_rad(1.5))), int(ceil(angle * sweep_reach(entry) / SWEEP_STEP))))
```

```gdscript
## Atmosphere kit: sky, depth fog and mist; a crisp overview; a far backdrop that is scenery only.
static func atmosphere_cases(g: Node3D, failures: Array[String]) -> void:
	g.build_level()
	var env: Environment = g.environment
	if env == null or not env.fog_enabled or env.background_mode != Environment.BG_SKY: failures.append("The world needs sky and fog")
	if g.overview.environment == null or g.overview.environment == env or g.overview.environment.fog_depth_begin <= g.definition.overview_distance(): failures.append("The overview must keep haze beyond its composition")
	var backdrop: Node3D = g.world.get_node_or_null("Backdrop")

			if mass in g.obstacles: failures.append("Backdrop must never be an obstacle")
```

```python
"""Generates world/backdrop.tscn: far megastructure silhouettes rising out of the mist.
Scenery only (no gameplay). Seeded, so regenerating gives the same world."""
import math, pathlib, random
rng = random.Random(7)
res = ['[sub_resource type="StandardMaterial3D" id="Stone"]\nalbedo_color = Color(0.2, 0.21, 0.25, 1)\nroughness = 0.9\n']
nodes = ['[node name="Backdrop" type="Node3D"]\n']
for i in range(26):
    angle = rng.random() * math.tau
    distance = rng.uniform(450, 1600)
    width = rng.uniform(40, 160)
    height = rng.uniform(250, 900)
    depth = width * rng.uniform(.4, 1.4)
    y = height * .5 - rng.uniform(250, 450)
    yaw = rng.random() * math.pi
    res.append('[sub_resource type="BoxMesh" id="Mass%02d"]\nsize = Vector3(%g, %g, %g)\n' % (i, width, height, depth))
    c, s = math.cos(yaw), math.sin(yaw)
    nodes.append('[node name="Mass%02d" type="MeshInstance3D" parent="."]\ntransform = Transform3D(%g, 0, %g, 0, 1, 0, %g, 0, %g, %g, %g, %g)\nmesh = SubResource("Mass%02d")\nmaterial_override = SubResource("Stone")\ncast_shadow = 0\n'
                 % (i, c, -s, s, c, math.cos(angle) * distance, y, math.sin(angle) * distance, i))
out = '[gd_scene load_steps=%d format=3]\n\n%s\n%s' % (len(res) + 1, '\n'.join(res), '\n'.join(nodes))
target = pathlib.Path(__file__).resolve().parents[1] / 'world' / 'backdrop.tscn'
target.parent.mkdir(exist_ok=True)
target.write_text(out, encoding='utf-8', newline='\n')
print('wrote', target)
```
